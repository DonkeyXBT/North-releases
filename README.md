# North

Downloads for North, a desktop toolbox for mail, profiles, inventory and automation.

## Install

1. Open the [latest release](https://github.com/DonkeyXBT/North-releases/releases/latest).
2. Download `North-Setup-<version>.exe` and run it.

North installs for your Windows account and needs no administrator rights. The installer is not
code-signed, so Windows SmartScreen may ask you to confirm: choose **More info**, then **Run anyway**.

## Updates

An installed North checks this page for a newer version when it starts and every few hours after
that. It downloads the update in the background and asks you to restart; if you choose Later, the
update is installed when you close North. Your vault is not touched by an update.

This repository holds only the installer. The other files on a release (`latest.yml`, `.blockmap`)
are what the updater reads.
